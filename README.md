# Flight Pomodoro App

Flight Pomodoro App is a web-based study and productivity timer that simulates real-time commercial flights during your work sessions. It features an interactive 3D aircraft model (built with Three.js) and active flight path tracking across a rendered globe (via Globe.gl), combining Pomodoro intervals with realistic flight-simulating visuals.
